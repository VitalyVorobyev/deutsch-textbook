Date: 2026-07-28

## Semantic job

Show one relationship: the event in the `nachdem` clause occurs before the
event in the main clause. The earlier event is marked with Plusquamperfekt;
the later event uses Präteritum in written narration, with Perfekt named only
as the spoken alternative.

## Selected composition

Use two numbered event cards connected by a single time arrow:

1. `Nachdem ich die Prüfung bestanden hatte,` — earlier —
   `Plusquamperfekt: hatte/war + Partizip II`.
2. `feierten wir die ganze Nacht.` — later — `Präteritum`.

Use deterministic HTML/CSS and an inline SVG arrow. On narrow screens, stack
the events and rotate the arrow downward. Pair colour with numbering, temporal
labels, tense labels and position. Provide complete EN/RU/UK text descriptions.
The figure is model input and creates no learner evidence.
