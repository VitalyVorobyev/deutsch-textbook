# Proposals

A proposal is a direction **under discussion**: the question, the forces, the constraints any
answer must respect, and the decisions still open. It authorizes nothing. A proposal ends in one
of two ways: an [ADR](../adrs/README.md) records the decision, and the proposal is deleted in the
same change; or the direction is dropped, and the proposal is deleted.
