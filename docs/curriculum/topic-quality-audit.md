# A1–B1 topic-quality audit ledger

This ledger tracks the bounded, topic-by-topic content pass required by P27-3g. It uses the
[content-quality audit contract](../authoring/content-quality-audit.md) and covers the whole topic
profile: article, outcomes, teaching sequence, delayed probes, readings, audio/documents and owned
vocabulary.

`Pass complete` means those surfaces were inspected together and material defects found in the pass
were corrected. It is **not** a claim that a human editor approved a draft topic, nor that learners
have mastered it. The manifest's `status` and provenance records remain the approval source of
truth.

  merely because this bounded pass and automated gates succeed.

### Dense-set ruling

Ten A2 topics cross the five-set review threshold. Each surviving set above has one named learning
activity, stage and decision or medium. The four Dativ remediation sets are the only especially
large cluster; they remain separate because learner evidence can arm article, preposition, noun-form
or pronoun recovery independently. `sets >= 5` therefore remains a review trigger, not a defect and
not a permission to add counts. A future set that cannot name a distinct decision, context and
stage should be merged or removed even if the topic's total item count then falls.

### Language and vocabulary sampling

All 271 entries in the 19 topic-owned A2 decks were checked mechanically for Russian fields
containing Ukrainian-only letters and Ukrainian fields containing Russian-only letters; none were
found. The profile pass also sampled gender, plural, IPA, verb paradigms, valency, independent
EN/RU/UK glosses and examples. Equality between RU and UK remains a review signal, not an automatic
error. A2 introduces no fresh Wortliste deck through a topic owner.
