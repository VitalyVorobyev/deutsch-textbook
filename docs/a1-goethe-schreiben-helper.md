# Goethe A1 Schreiben — Helper

## Scoring

For Schreiben Teil 2:

- Inhaltspunkt 1: **3 / 1.5 / 0**
- Inhaltspunkt 2: **3 / 1.5 / 0**
- Inhaltspunkt 3: **3 / 1.5 / 0**
- Textsorte / form: **1 / 0.5 / 0**

Maximum: **10 points**

Main rule: complete all three communication tasks clearly. Grammar and spelling errors are less dangerous if the meaning stays understandable.

---

# Core exam strategy

1. Read the three bullet points.
2. Mark them mentally as **1 / 2 / 3**.
3. Write at least one clear sentence for each.
4. Use a correct greeting.
5. Use a correct closing.
6. Prefer simple, reliable German over complicated sentences.
7. Before finishing, check:
   - Did I answer all 3 points?
   - Did I accidentally change the meaning?
   - Did I forget `nicht`?
   - Are dates/times correct?

# Declining an invitation

# Useful connectors

- weil
- aber
- und
- oder
- deshalb
- leider
- gerne
- bitte

At A1, `weil` is useful, but do not force complicated subordinate clauses if a simple sentence is safer.

Example:

> Leider kann ich nicht kommen. Ich muss arbeiten.

This is completely acceptable.

# Dangerous mistakes to check

- `nicht` forgotten
- wrong person: `ich` vs `du`
- wrong city/date copied from task
- `Liebe Anna`, not `Lieber Anna`
- `Lieber Thomas`, not `Liebe Thomas`
- `Viele Grüße`, not `Viele Größe`
- `mit einem Balkon`
- `in die Schweiz`
- `Frühstück`
- `Wie hoch ist der Preis?`
- `Wie hoch ist die Miete?`
- `vom ... bis zum ...`
